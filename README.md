# Hybrid Explainable Stock Prediction System with Sentiment Analysis And Explainable AI

An AI-powered stock market prediction and analysis platform that combines machine learning, sentiment analysis, explainable AI, and interactive dashboards to help users make smarter investment decisions.

## Overview

The **Hybrid Explainable Stock Prediction System with Sentiment Analysis and Explainable AI** is designed to provide intelligent stock market insights by integrating predictive analytics with explainable artificial intelligence techniques. The system analyzes historical stock data, market trends, and news sentiment to generate stock predictions while also explaining the reasoning behind those predictions.

The platform offers an interactive dashboard, real-time market insights, smart alerts, and AI-assisted explanations to improve transparency and user trust.

This project is divided into multiple core modules:

* **Stock Prediction Module** – Predicts stock trends using AI/ML models
* **Explainable AI Module** – Provides understandable explanations for predictions
* **News Sentiment Analysis Module** – Analyzes market news and sentiment impact
* **Historical Comparison Module** – Compares current market patterns with historical data
* **Smart Alerts Module** – Sends intelligent stock movement alerts
* **Market Expert Chat Module** – AI-assisted stock market guidance and interaction
* **User Dashboard Module** – Personalized dashboard for tracking stock performance
* **Authentication & User Management Module** – Secure login and user session handling

# How to Run the Project

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/hybrid-explainable-stock-prediction-system.git
cd hybrid-explainable-stock-prediction-system
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Start the Development Server

```bash
npm run dev
```

## 4. Open the Application

Visit the following URL in your browser:

```bash
http://localhost:5173
```
